# Phase 1: Foundation (Days 001 – 030)

> **Core Objective**: Establish your voice, introduce who you are, set up your public learning journey, and signal discipline and technical curiosity. People should begin recognizing your name as someone dedicated to mastering cloud systems and DevOps fundamentals.

---

## Phase Overview

- **Timeline**: Month 1 (Days 1 to 30)
- **Primary Themes**:
  - The "Why": Why Cloud & DevOps engineering?
  - Systems Fundamentals: Linux core concepts, file systems, permissions, shell automation
  - Networking Basics: How packets travel, IP addressing, DNS resolution, ports & sockets
  - Version Control Mastery: Git internals, branching strategies, commit cleanliness
  - Establishing Public Discipline: Building the daily habit, sharing daily breakthroughs

## Weekly Breakdown

| Week | Focus Area | Recruiter Signal |
|---|---|---|
| **Week 1 (Days 1–7)** | Identity, Commitment, Linux Foundations | Sets high baseline for clarity, personal accountability, and systems curiosity. |
| **Week 2 (Days 8–14)** | Linux Deep-Dive & Shell Scripting | Signals familiarity with terminal automation and operating system mechanics. |
| **Week 3 (Days 15–21)** | Networking Fundamentals (DNS, HTTP/S, TCP) | Shows understanding of distributed communication protocols underlying all clouds. |
| **Week 4 (Days 22–30)** | Git Internals, CI/CD Concepts & Month 1 Review | Demonstrates professional development hygiene and structured reflection. |
