# Phase 2: Knowledge (Days 031 – 090)

> **Core Objective**: Become genuinely useful to the audience. Move from introducing who you are to establishing a reputation for crystal-clear technical explanations. When people read your content, their immediate thought should be: *"This person explains complex cloud concepts better than most textbooks."*

---

## Phase Overview

- **Timeline**: Months 2 & 3 (Days 31 to 90)
- **Primary Focus Areas**:
  - **Month 2 (Days 31–60)**: Deep Containerization & Docker Internals. Namespaces, cgroups, UnionFS/Overlay2, multi-stage optimization, distroless images, container networking, and multi-tier Docker Compose stacks.
  - **Month 3 (Days 61–90)**: Cloud Architecture & Infrastructure Foundations. AWS core primitives (IAM least-privilege, VPC topologies, EC2/ALB routing, S3 security), Infrastructure as Code (IaC) theory, and the architectural foundations of Kubernetes (Control Plane vs Worker Nodes).

---

## Weekly Rhythm & Modules

### Month 2: Containers & Docker Internals (Days 031 – 060)
- **Week 5 (Days 31–37)**: Container Runtimes & Kernel Isolation Primitives (Namespaces, Cgroups, Chroot).
- **Week 6 (Days 38–45)**: Dockerfile Optimization, Layer Caching, Multi-Stage Builds, and Distroless Images.
- **Week 7 (Days 46–52)**: Container Networking (Bridge, Host, Overlay) & Persistent Storage Volumes.
- **Week 8 (Days 53–60)**: Docker Compose Multi-Service Architecture, Healthchecks & Month 2 Capstone.

### Month 3: Cloud Infrastructure & Distributed Systems (Days 061 – 090)
- **Week 9 (Days 61–67)**: Cloud Governance & Security: IAM Roles, Policies, Service Accounts, and Least Privilege.
- **Week 10 (Days 68–75)**: Cloud Compute & Storage: EC2 Lifecycle, Auto Scaling Groups, EBS vs S3.
- **Week 11 (Days 76–82)**: Production Cloud Networking: VPC Topology, NAT Gateways, Security Groups vs NACLs, ALB vs NLB.
- **Week 12 (Days 83–90)**: Infrastructure as Code Theory & Introduction to Kubernetes Architecture (etcd, Kubelet, Scheduler) + Month 3 Review.
